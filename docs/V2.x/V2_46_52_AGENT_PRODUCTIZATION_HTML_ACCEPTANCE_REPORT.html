2. 目标架构

目标是把已有 V2 项目智能 artifacts 产品化为人类和 Codex/Copilot 类 Agent 可消费的入口：人类看 Portal，Agent 走 MCP/CLI/HTTP，治理走 feedback/rule/overlay，最终用 closure matrix 证明每个 accepted row 都有证据。

3. 当前架构实现

核心实现模块

  • `mcp_usage.py`：MCP 工具目录、Codex 使用指南、Agent workflow。
  • `profile_onboarding.py`：项目 profile、taxonomy、authority/path pattern、no-hardcode audit。
  • `human_portal.py`：Portal model、SVG 图、HTML 项目理解页。
  • `task_navigation.py`：任务阅读路径、影响候选、建议测试。
  • `governance.py`：feedback、rule build、approve/revoke、read-time overlay。
  • `playbooks.py`：四类 Agent role playbook。
  • `closure.py`：real repo matrix、parity、redaction、closure report。

三端入口

  • HTTP：`backend/app/api/v1/code_assets_agent_productization.py`
  • MCP：`backend/data_service/mcp_code_agent_productization_tools.py`
  • CLI：`backend/data_service/cli_code_agent_productization.py`
  • Public surface guard 已覆盖新增工具和路由。

4. 用户场景体验路径

1

新维护者快速读项目

导入项目后生成 Portal，先看 one-liner、模块、图表、风险和 blockers，再决定深入读哪些文件。

可体验内容：Human Portal HTML、SVG 架构概览、profile/taxonomy。

2

Codex/Copilot Agent 准备开发任务

Agent 先读取 MCP Guide 和 Playbook，再为具体任务生成 reading order、impact candidates、suggested tests，减少全仓扫描。

可体验内容：MCP workflow、coding_agent playbook、task navigation。

3

架构审计者看文档/代码风险

通过 Portal 和 Governance Overlay 查看哪些内容需要 review，批准或撤销规则时只做 read-time overlay，不改写原始 artifact。

可体验内容：feedback、rules、approve/revoke、overlay。

4

持续验收与交付

最终生成 closure matrix，确认每个 accepted row 都有 artifact evidence，并检查 parity、redaction、fatal/major。

可体验内容：real repo matrix、public contract parity、redaction audit、closure report。
