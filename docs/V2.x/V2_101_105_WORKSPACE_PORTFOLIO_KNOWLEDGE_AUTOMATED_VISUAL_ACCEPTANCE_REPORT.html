7. False-green 审计

  • 未把 scan-only evidence 当作完整项目理解。
  • 未把 UI 截图或页面可打开当作 build evidence。
  • 未把 OCR 缺失的图片/扫描件写成 accepted。
  • 未把 docs claim 写成 code fact。
  • 未构建项目保留 needs_review，没有 silent skip。
