data_service 自动化可视化验收

目标：用真实 data_service 仓库构建项目智能 artifact，并用无头 Chrome 截图记录用户可见体验。

目标架构

PRDProject IntelligenceEvidence-first

  • Codebase Asset Registry：导入本地代码仓库。
  • Snapshot / Inventory / Symbol / Trace：生成结构化代码事实。
  • Overview / DevWiki / Agent Context Pack：向人类和 Agent 输出项目理解材料。
  • Architecture / Governance：文档 claim 与 code fact 分离。
  • Portal / Dashboard：展示 accepted、needs_review、structured_unavailable，不隐藏风险。

当前实现

  • 真实仓库 snapshot 文件数：3147
  • 公开 surface 数：669
  • 符号数：29644
  • Dashboard 面板数：5
  • 外部项目路径：data_service accepted；codexPat/HarnessOS/Navia structured_unavailable。

用户场景路径

用户路径验收信号
维护者打开 Portal / Dashboard 查看当前能用什么、风险在哪里、下一步做什么。非 accepted 状态保持可见；外部不可用未被误写 accepted。
Coding Agent读取 codebase snapshot、public surface、context pack、baseline，再决定修改入口。所有关键输出有 artifact refs 或明确 unresolved。
架构审计者比对 PRD 目标、当前实现、public surface baseline 和 delivery manifest。不声称 full call graph / runtime topology / data-control flow / type inference。
